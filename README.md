# Co-Intelligence 共智 · 中文共读译本

> Ethan Mollick《Co-Intelligence: Living and Working with AI》的中英对照共读翻译，按"每天一个阅读单元"的节奏逐单元沉淀而成。

## 关于本书

- **原书**：*Co-Intelligence: Living and Working with AI*
- **作者**：Ethan Mollick（沃顿商学院教授，One Useful Thing 时事通讯作者）
- **出版**：Portfolio / Penguin（2024）
- **主题**：如何与 AI 共处与协作——从 LLM 的技术原理出发，依次讨论 AI 作为同事、创造者、教师、教练与未来图景，落点是"与一个外星心智共同思考"

## 内容结构

每个单元包含五个部分：

1. **本单元讲了什么**——内容概要，三五分钟读完全单元精华
2. **英文原文**——对应书页的英文原文（含小节标题）
3. **中文翻译**——完整中译，术语随文注释
4. **核心观点**——可检索的要点列表
5. **金句**——中英对照摘录

- 原文中的口号、引文等英文内容随文保留并附译文
